# Git Project

## Описание проекта
Учебный веб-проект, созданный в рамках ЛПР для освоения методологии ветвления Git (Git Flow) и правил структурирования коммитов.

## Настройка разработки
1. Клонируйте репозиторий:
   `git clone https://github.com/Lachowski262/git-project.git`
2. Откройте проект в редакторе Visual Studio Code:
   `code git-project`
3. Для просмотра верстки откройте файл `index.html` в веб-браузере.

## Руководящий документ
Разработка и ведение веток регламентируются руководящим документом ЛПР (инструкция по работе с ветками и правила оформления коммитов).
